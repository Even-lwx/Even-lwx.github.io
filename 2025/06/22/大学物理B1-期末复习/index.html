几类典型模型的磁感应强度总结

一、载流长直导线的磁场

情况描述 磁感应强度公式
导线有限长 B=μ0I4πa(cos⁡α1−cos⁡α2)B = \frac{\mu_0 I}{4\pi a}(\cos\alpha_1 - \cos\alpha_2)
导线无限长 B=μ0I2πaB = \frac{\mu_0 I}{2\pi a}
特殊情况：场点位于直导线延长线上 B=0B = 0

二、载流圆线圈轴线上的磁场

位置 磁感应强度公式
圆心点OO处 B=μ0I2aB = \frac{\mu_0 I}{2a}（aa为线圈半径）
远离线圈处（x≫ax\gg a，xx为轴线到线圈距离） B=μ0Ia22x3B = \frac{\mu_0 I a^2}{2x^3}

三、载流长直螺线管内的磁场

  • 无限长螺线管：B=μ0nIB = \mu_0 nI（nn为单位长度匝数，II为电流）
  • 有限长螺线管（长为ll）：（文档未具体给出，可补充：轴线上某点磁场需结合积分计算，中心处近似为无限长情况）

四、长直圆柱形载流导线内外的磁场

位置 磁感应强度公式
导线外部（r>Rr > R，RR为导线半径） B=μ0I2πrB = \frac{\mu_0 I}{2\pi r}
导线内部（r<Rr < R） B=μ0Ir2πR2B = \frac{\mu_0 I r}{2\pi R^2}

五、载流螺绕环内的磁场

  • 当环形螺绕线管横截面积很小时，设圆环平均长度l=2πrl = 2\pi r，环内磁感应强度：B=μ0NI=μ0nIB = \mu_0 NI = \mu_0 nI(NN为总匝数，n=Nln = \frac{N}{l}为单位长度匝数）

注：以上所有公式均可由安培环路定理或者毕奥—萨伐尔定理推导得出。
